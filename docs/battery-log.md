# 电压历史记录（2026-10-23）

sensor任务从本次开机第1分钟开始，每分钟追加一次电池快照中的滤波`voltage_mv`和开机秒数。沿用当前PA1/ADC1采样与1/8滤波，不新增ADC读取；亮屏、熄屏待机、运动模式都记录。ADC无效时等待有效值，任务延迟跨过多个分钟时只记录当前点，不补造历史。计时复用`app_uptime`，包含Tickless补时并支持HAL tick回绕，不受手机校时影响；记录的是开机经过时间，未保存日历日期。

## Flash分区和记录

2026-10-26 起，同一日志追加保存重启现场。每条复位历史占 17 个槽（136 字节），每次开机先写一个共用的开机标记；原有电压记录保留，电压导出与样本计数会跳过复位槽。占用槽数包含复位现场。`RESET,HISTORY` 可读取完整历史，协议及格式见 [复位诊断](reset-diagnostics.md)。`BATLOG,CLEAR` 会同时删除电压与复位历史并重启。

日志独占内部Flash sector 7：`0x08060000～0x0807FFFF`，128KiB，共16384个8字节槽。普通APP限制为384KiB，升级APP限制为352KiB，Bootloader最大APP镜像为360448字节。EEPROM校准及开机时长记录不变。

每槽小端：偏移0为32位开机秒数，偏移4为16位电压mV，偏移6为前6字节的CRC16（多项式`0x1021`，初值`0xB471`异或开机编号低/高16位）。电压`0xFFFF`表示开机标记，此时偏移0是开机编号，CRC初值固定为`0xB471`。每次开机第一次记录前写入一个开机标记；后续数据的CRC绑定此编号。单次连续开机最多16383个电压点，约11.4天；反复开机还会占用标记槽。

启动扫描占用槽并保留旧记录；只追加到尾部，不重复编程坏槽。每条最后写CRC，写后刷新Flash数据缓存并读回校验。写满停止；写失败停止本次开机的追加并报告ERROR，下次启动重新扫描。导出跳过CRC错误记录，开机标记损坏后不会把其数据接到上一次开机曲线上。第一个槽不是有效开机标记时报告NEED_CLEAR，保留区域内容，必须明确清空才启用记录。

编程按半字进行，半字之间允许UART中断；内部Flash编程仍可能短暂停顿取指，真实采样抖动及115200波特率接收完整性需要上板验证。正常记录从不擦除Flash。

## 手机操作

连接`F411-Watch`的BLE，订阅FFF1 Notify，使用现有收发界面发送ASCII命令并开启“追加换行”。下面的每条命令末尾都要发送实际LF或CRLF；不是两个字符`\`和`n`。命令无需先校时，一次发一条并等待响应；连续分包间隔需小于1秒。

| 命令 | 行为 |
| --- | --- |
| `BATLOG,STATUS` | 查询样本数、已占槽数、总槽数和状态 |
| `BATLOG,READ` | 导出请求时已有的全部有效电压记录 |
| `BATLOG,STOP` | 停止导出，不删除数据 |
| `BATLOG,CLEAR` | 删除全部电压与复位历史并重启手表 |

状态示例：`BATLOG,STATUS,100,102,16384,1`，依次为电压点数、占用槽数、总槽数、状态。状态0=STARTING、1=READY、2=FULL、3=NEED_CLEAR、4=ERROR。占用槽包含开机标记和坏槽。

导出示例：

```text
BATLOG,BEGIN,3,5
BATLOG,DATA,1,1,60,3980
BATLOG,DATA,2,1,120,3975
BATLOG,DATA,4,2,60,3960
BATLOG,END,3
```

BEGIN为请求时有效点数、占用槽数。DATA为槽序号、开机编号、开机秒数、电压mV。相同开机编号的数据属于同一条曲线；例如`DATA,2,1,120,3975`表示第1次开机经过120秒时3975mV。END为期望有效点数；手机应核对实际收到的DATA数量和槽序号，缺失时重新READ。导出不会清除或停止后台记录，BEGIN之后新追加的点留到下一次READ。

复用原LVGL蓝牙上下文和异步UART发送，每行完成后至少间隔100ms，不连续灌满模块缓存。导出期间暂停心率调试波形并保持亮屏；PA4熄屏、进入运动模式、串口接收错误会取消导出，记录继续。UART发送失败停止本次导出，等待手机重新请求。UART完成不代表手机确认收到，协议未添加手机ACK。接近满容量的完整导出可能需要约半小时，可用STOP结束。本次没有修改安卓APK或增加手机曲线页面，手机可将文本保存后按开机编号绘图。

## 清空与升级

CLEAR先回复`BATLOG,CLEARING_REBOOT`，UART完成后留300ms发送窗口，再取得日志互斥锁、屏蔽TPS3823外部复位、关闭中断，仅擦除sector 7，然后立即软件重启。不启用内部IWDG，擦除期间没有看门狗保护；擦除异常停滞时不会由看门狗复位。擦除成功或失败均重启，重新连接后STATUS应为零点/READY才算清空成功；擦除失败可能保留旧内容或变成NEED_CLEAR。普通熄屏不取消清空；进入运动模式或通信错误会取消。电压历史清空是显式维护动作，会中断测量和蓝牙连接；EEPROM中的校准与开机时长不受影响。模块发送窗口不等于手机收件确认。

**部署时须同时更新新Bootloader。**旧Bootloader仍允许镜像进入sector 7，不能保证日志保留。用SWD下载时选择按覆盖扇区擦除；整片擦除会删除历史。重新生成CubeMX工程后，也须保留APP分区边界及新增模块。Flash写入/擦除时应保持正常供电。
