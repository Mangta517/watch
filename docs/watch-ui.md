CPU Sleep / STOP / Tickless：所有应用任务阻塞后，由FreeRTOS提供下一任务截止时间，运行时保持1ms SysTick。BLE供电或USART1仍开启、亮屏背光PWM、SPI/DMA/ADC有在途操作时保留Sleep；BLE断电、USART1时钟关闭、屏幕熄灭且上述外设空闲，预计至少5ms空闲时进入低功耗调压器STOP。F411 STOP会停止USART/APB时钟，选择保连时BLE待机始终使用Sleep保证既有串口接收，其单次Sleep受SysTick 24位容量限制为最多199ms；默认ECO熄屏关闭BLE、外设空闲时进入STOP，基础服务及加速度读取保持200ms；Tickless单次请求上限400ms，实际等待受最近任务截止时间及唤醒条件约束，SPORT熄屏同样在采样间隙使用STOP。双任务看门狗条件、100ms最小喂狗间隔及启动宽限不变，Sleep/STOP均不暂停或额外喂狗。Bootloader不运行FreeRTOS，保持原时基。

STOP进入前暂停SysTick，以LSE/16的RTC WUT提前唤醒，预留约1ms恢复余量；PA4、RTC及其它未屏蔽中断可提前唤醒，MPU DATA_RDY/PB12 EXTI在STOP期间屏蔽，已置位pending保留。PB2/WDI始终保持推挽输出、PB1/WDG_EN保持低电平，外部看门狗连续计时。醒来在中断仍屏蔽时检查PVD，供电正常才有界恢复84MHz PLL、清RSF并等待RTC影子同步，使用一分钟内秒与亚秒计数的模差值补齐HAL/FreeRTOS，并补上TIM2诊断计数停钟时间；最后恢复原tick相位、1ms节拍并开放中断。最后的到期tick交正常ISR处理，不用vTaskStepTick跨过解阻塞点。时钟恢复及RTC等待均不依赖暂停的HAL tick。RTC未就绪退回1ms Sleep，WUT配置失败退回Tickless Sleep；STOP返回后若欠压、RTC影子同步失败或无法取得结束计数，则撤销RTC唤醒定时器并进入Error_Handler保存现场、主动复位，避免在供电异常或睡眠时长未知时继续运行；PLL恢复超时同样进入Error_Handler。RTC/LSE停振且没有其它唤醒中断时，外部看门狗仍能超时复位，无需等待STOP返回；已停止的SysTick不承担STOP唤醒，详见[看门狗说明](watchdog.md)。

RTC使用LSE，异步/同步分频改为0/32767，日历仍为1Hz，亚秒分辨率约30.5us；同步计数频率升高的RTC自身功耗代价也须计入整板测量。首次升级时迁移已初始化备份域的分频，保留日历及备份标记，迁移会重新开始亚秒相位。休眠取一分钟内RTC秒与亚秒计数，按一分钟模数求差，可覆盖完整1秒、跨分和午夜；手机校时在应用任务恢复后执行，因此不会改变超时、采样或开机累计时间。DWT周期计数补偿RTC测量区间之外的停表计算开销，不依赖DWT在Sleep/STOP中计数；RTC量化和最后几条寄存器操作仍有有限误差，长期精度须实测。普通熄屏的5Hz加速度帧只供计步/辅助抬腕使用，不推进完整姿态融合；进入姿态模式后按原流程预热和恢复。当前熄屏显示循环无按键时等待PA4/UART通知或200ms期限，消抖/按住期间约20ms推进，触摸任务在芯片休眠后阻塞，实际连续睡眠受最近任务截止时间限制；200ms是服务等待上限，不代表每次能睡满。

2026-11-15自动熄屏：仅表盘页（`PAGE_WATCH`）亮屏且无切页动画时，连续10秒无操作才自动熄屏；APPS菜单（`PAGE_SETTINGS`）与全部功能详情页保持常亮。由功能页或菜单返回表盘时重置活动计时，重新等待完整10秒，包含`App_UI_Back()`、PA5及手势返回。功能页不周期性刷新LVGL活动时间；所有页面仍支持PA4手动熄屏，PA4或辅助抬腕唤醒后保留原页面，功能页继续常亮。停留功能页会持续消耗背光和亮屏业务所需电量，观察结束后可按PA4熄屏或返回表盘。

自动熄屏与PA4手动熄屏共用同一处理函数：背光为0%，暂停显示刷新及LVGL绘图/动画，禁用触摸并清空缓存，蓝牙沿用当前ECO/保连选择；LCD等待在途DMA正常完成或100ms超时安全收尾后发Sleep In，触摸由其独占任务发送休眠命令，随后通过任务通知无限等待PA4唤醒。自动熄屏后触摸不能唤醒，由PA4或辅助抬腕恢复；恢复原亮度、当前RTC时间和原页面位置，LCD发Sleep Out并等待至少120ms后恢复显示，触摸任务通过通知唤醒、复位及探测芯片（复位等待约310ms），等待原触点松开后才接收新手势。持续触摸及亮屏按键操作仍算活动。运动、心率及校准所需采样按各自原策略处理，CPU使用上述Sleep/STOP混合策略。

## 页面与交互

`app_touch.c`用32项静态事件缓冲保留按下、移动及释放顺序；LVGL回调只在短临界区取数，通过`continue_reading`消费积压，不做I2C或等待。最近采集或队首事件超过100ms、缓冲满时取消旧手势并等待物理松手，避免长按卡住或回放旧点击。熄屏停止新轮询、清空缓存，由touch任务在芯片休眠命令写入成功后阻塞等待PA4通知；写入失败时不报告为已休眠，首次立即重试、其后按500ms退避每次重试一笔，不读取触点，亮屏通知可打断等待；亮屏通过任务通知恢复触摸复位及探测，清缓存并等待原触点释放；跨熄屏切换的在途I2C结果被丢弃。所有LVGL API仍仅由显示任务调用，看门狗保持原显示/sensor双任务进度条件。
