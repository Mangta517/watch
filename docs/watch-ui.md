# SYDNEY 圆形表盘与功能入口

本界面直接使用项目现有的 LVGL 8.2、ST7789 240×280 显示驱动和 CST816 触摸驱动。启动入口为 `App_UI_Create()`，RTC驱动与校时解析模块已加入Keil工程。开机先完成LCD/触摸初始化并刷新首帧，再在LVGL任务内初始化RTC及蓝牙；此期间界面暂时停留在首帧。随后创建原有sensor任务，在后台初始化传感器、恢复校准并采样；未获得数据时显示占位或现有状态。

## 页面与交互

| 页面 | 内容 | 操作 |
| --- | --- | --- |
| SYDNEY | 236×236居中圆形深蓝表盘（左右各留2像素，上下各留22像素）、上下大号时分、歌剧院/海港大桥/海面剪影、天气与心率摘要 | 左滑打开功能网格；点击天气/心率直接进入详情，点击大号时间进入Bluetooth校时；上下拖动不滚动也不触发入口 |
| APPS | Heart rate、Motion、Barometer、Climate、Weather、Bluetooth、Display七个独立入口控件 | 上下滚动网格，点击进入对应详情；右滑或BACK返回表盘 |
| HEART RATE | BPM、测量状态、原始信号与周期诊断 | START/STOP控制现有心率测量 |
| MOTION | Pitch/Roll/Yaw、磁场三轴、融合来源及校准状态 | 上下滚动查看；CALIBRATE MAG/FINISH CALIBRATION沿用原校准接口 |
| BAROMETER | 气压、标准海平面气压估算海拔及传感器状态 | 上下滚动查看 |
| CLIMATE | AHT21空气温湿度、采样次数及CRC/I2C等状态 | 自动更新 |
| WEATHER | 手机天气、温度、湿度及距同步时间 | 由现有BLE天气协议同步 |
| BLUETOOTH | BLE初始化结果、接收内容、发送及校时结果 | SEND TEST发送测试文本；CLEAR清空接收记录 |
| DISPLAY | 背光亮度 | 拖动滑块调整10%–100%亮度 |

SYDNEY与APPS两张主页面在横向边缘停止切换，不循环跳页。每个功能通过独立控件进入独立详情页，不再把全部数据堆在设置长页中。圆盘最外围为8像素黑色表圈，外缘完整细白圆线与内缘灰色圆线形成同心描边，不使用方形轮廓；城市剪影、数字和摘要均按圆形遮罩裁切；参考图里的日期、步数和电量百分比没有对应的真实服务，界面沿用实际天气、心率和电池电压数据。

详情页右滑、点击标题或BACK、按侧键，均通过原访问历史返回，并恢复入口网格的纵向滚动位置。主表盘不显示标题、APPS文字、页码圆点或其他圆盘外元素，圆盘外保持纯黑；APPS与各详情页继续显示原有标题、返回入口及功能区圆点。

实体键使用已有 `KEY_1`（PA5，上拉输入，低电平按下）。按下和释放均做 30 ms 消抖，释放后触发一次返回；持续按住不会连续返回。返回按实际访问历史执行，并恢复上一页的纵向滚动位置。无历史时按键保持当前页面。历史保存最近 16 次页面访问。

电源键 SW2 使用 `WAKE`（PA4，上升沿 EXTI4、无内部上下拉、中断优先级 13）。UI 定时器扫描电平，按下和释放均做 30 ms 消抖，按下消抖通过后切换背光：熄屏设为 0%，亮屏恢复亮度滑块原值；按住不重复切换，开机时按住 SW2 后首次松手不会熄屏。熄屏期间暂停触摸输入和 PA5 返回操作，保留页面、滚动位置和亮度；亮屏时等待已有触点释放。EXTI4 仅由 HAL 清除中断，不在 ISR 中调用 LVGL 或背光接口。

PA3 `POWER_EN` 在 `main()` 入口、HAL和系统时钟初始化前就设置为高电平输出，随后CubeMX GPIO初始化继续保持高电平，保持 TPS63020 供电；`.ioc` 同步设置初始高电平，重新生成代码后仍保留。当前熄屏仅关闭背光，LCD、MCU、传感器和蓝牙继续运行，不进入 Sleep/Stop，也不执行长按关机。

横向滑动使用 LVGL 手势，累计 40 px 位移触发，触摸芯片重复上报坐标时仍保留累计位移，支持慢速滑动。圆盘显示数字时间、城市剪影及天气/心率快捷控件；功能网格和详情页的纵向滚动仅作用于中间内容区域，标题和底部位置指示固定。亮度滑块不向页面传递横向手势。页面切换在手指释放后执行，使用 160 ms 动画并自动删除旧页面，避免在触摸回调中删除事件对象。动画期间忽略新的页面点击和手势；实体键返回会排队等待动画结束。

按用户要求保留原触摸和显示配置：LVGL任务、触摸读取、显示刷新调度均为5ms；调度周期不代表屏幕实际帧率。界面数值仍每100ms更新。触摸连续失败200次后恢复，维持约1s的原恢复节奏。主频100MHz、RTOS tick1000Hz保持原配置；PA4仅切换背光，不改变MCU运行模式。

## 配色与数据

圆盘外围为纯黑；表盘与功能页背景 `#041426`，卡片 `#0C2238`，分隔与轨道 `#173B54`；浅蓝 `#70C5E8` 与白色 `#F4FAFF` 对应SYDNEY参考图。现有传感器重点数据继续使用橙/绿/红色。复用现有Montserrat 10/14/20/30字体，大号数字使用从Barlow Condensed SemiBold矢量字体以4倍分辨率采样生成的44×80、4bpp子集字体，仅含`-`与`0`～`9`，字模占19360字节Flash，不使用运行时缩放缓冲。矢量源及SIL OFL 1.1许可随附在`tests/ui/assets/`，固件字模为`application/ui_sydney_font.c`，可手动运行`python tests/ui/generate_sydney_font.py`重生成。歌剧院帆顶使用细分曲线轮廓；海港大桥采用较平缓的二次曲线桥拱、浅色细吊索及独立桥面，海面使用分层蓝色横带。城市和表圈使用原生LVGL图元；20×20心形由连续三次贝塞尔曲线按16倍分辨率采样，400字节透明度数据存于Flash，以8位透明度平滑绘制，主表盘、网格入口和心率详情共用。固件界面采用英文，沿用当前字库；`LV_USE_PERF_MONITOR`保持关闭。

姿态和气压每 100 ms 经 `App_IMU_GetSnapshot()`、`App_Baro_GetSnapshot()` 获取；UI 不直接访问传感器 I2C。无有效快照时显示 `NO DATA` 与 `--`。Yaw 由四元数反解到 (-180, 180]：有效磁场参与时以磁北为参考，失效时继续六轴相对递推。姿态页显示 `MAG NORTH`、`MAG UNCAL` 或 `GYRO ONLY`，并增加三轴磁场和旋转校准按钮。高度保持原有标准海平面气压估算方式。磁力计接线、校准与融合约定见 [magnetometer.md](magnetometer.md)。

表盘时间来自STM32内部RTC，使用已有32768Hz LSE晶振，预分频127/255，采用24小时制。小时在右上方、分钟在右下方，桥旁不显示秒数。时分读取同一RTC快照，只在文字变化时重绘；RTC内部仍按秒走时，蓝牙仍支持HH:MM:SS校时。首次未校时时分均显示`--`及`SET VIA BLE`，RTC不可用时显示`RTC ERROR`。点击大号时分进入Bluetooth页校时。

手机发送`14:35:47`即可校时为14:35:47；继续兼容`14:35`及`9:5`，省略秒时置零。可带CR/LF；不带换行时等待200ms接收空闲再解析。错误、超范围或过长的时间消息不覆盖现有时钟。校时结果在Bluetooth页显示，原始消息仍保留在接收日志。初始化通过RTC备份寄存器标记判断是否已有时间，复位时不重复清零；掉电保持取决于VBAT和LSE是否持续供电。手机发送时分秒，RTC日期为内部占位，不代表手机日期。

亮度默认50%，通过现有`LCD_Set_Light()`调节；重启后恢复默认值，尚未持久化到Flash。

圆盘心率摘要使用浅蓝色实心心形加BPM数字；Heart rate网格入口和详情页沿用相同心形图案。点击入口或圆盘心率控件打开独立心率页。点击START后，现有sensor任务重新确认EM7028 PID和配置，再开启HRS1采样及PB15外部照明；STOP关闭测量。UI每100ms读取互斥锁保护的快照，不访问I2C。有效波形显示BPM及TRACKING；等待、信号不足和故障分别显示MEASURING、NO SIGNAL、UNAVAILABLE，数值显示`--`。正常测量时显示HRS1原始值、AC变化幅度及最近检测到的PERIOD间隔（ms）；UNAVAILABLE时显示I2C读写、PID/配置读回不符或DATA CHANGED等失败原因及REG地址，具体含义见[em7028.md](em7028.md)。离开心率页不自动停止测量，需要点击STOP。

心率服务每30ms尝试采样，共用去背景、低通滤波后运行10%、20%、30%、40%、50%五档峰谷门限，各候选连续三个相近间隔后，按RR间隔方差最小选优，显示范围为40～200BPM。该选优思路参考HeartPy，来源和适配差异见[em7028.md](em7028.md)。门限最低8计数、完整周期峰谷差至少16计数；范围外或无有效候选显示`--`，不钳成40或200。超过250ms无有效采样、采样间隔超过120ms、弱周期或总线持续故障都会使旧BPM失效。算法尚需实板波形、噪声及参考心率对照校准。

Climate入口打开独立 AHT21 温湿度页，每 2 秒自动采样，显示湿度、空气温度、成功次数及 CRC/I2C/未校准/转换超时状态。UI 只读快照，80ms 转换等待由 sensor 任务分次处理，详见 [aht21.md](aht21.md)。

LVGL池继续保持44KiB；各详情页只创建自己的控件。2026-10-13 SYDNEY版本主机压力测试最低余量16776字节，覆盖200次主页面切换及70次功能页往返。FreeRTOS任务、栈配置和显示/触摸周期保持原值。

SYDNEY版本Keil构建为0错误、0警告：Code 191236字节，RO-data 112884字节，RW-data 1084字节，ZI-data 94572字节。主机模拟不能替代实板RAM峰值、光路、ADC更新周期与心率准确性验证。

圆盘底部显示电池电压，其余页面继续在右上角显示，例如 `BAT 3.85V`。PA1/ADC1_IN1 由现有 sensor 任务每秒单次采样，UI 只读取互斥锁保护的快照；开机在IMU零偏校准前先发布一次读数。1M/1M 分压按2倍还原，ADC参考电压暂按3300mV，实板可在 `app_battery.h` 的 `APP_BATTERY_VREF_MV` 中按实测VDDA校准。首次采样前显示 `BAT --.--V`，启动/转换/停止失败显示红色 `BAT ADC ERR`，下一秒自动重试。显示的是电压，不据此推断充电状态或电量百分比。

UI 保持每 100ms 读取快照，只在最终显示文字或颜色变化时设置控件；小数继续沿用原有截断规则，原始值变化但显示位数相同不会重复重绘。大号时分和摘要只在最终文字变化时更新，切页重建后直接比较新控件中的文字，无需额外缓存。

手机天气由蓝牙同步；圆盘左上分别用小字显示天气、大字显示温度，Weather详情页显示湿度及距同步时间，超过一小时标记旧天气。获取和协议见 [bluetooth.md](bluetooth.md)。

所有 LVGL 调用仍在显示任务中运行。其他任务若调用 `App_UI_Back()`，必须持有 `App_Display_Lock()`；中断中禁止调用。

## 验证与预览

Keil：构建 `MDK-ARM/f411ceu6.uvprojx`，输出仍位于 `MDK-ARM/f411ceu6/`。无需烧录即可编译，实际触摸手感与背光效果需要上板验证。

桌面验证使用项目真实的 LVGL 绘制器和输入引擎，只替换 GPIO、传感器快照和背光接口：

```powershell
python tests/ui/run.py
```

需要桌面 GCC（Windows 可使用 MinGW）、Python 和 Pillow。输出位于忽略跟踪的 `tests/ui/output/`，包含实际界面渲染图、主页/入口预览`watch-ui-preview.png`及七项功能详情预览`watch-ui-details.png`。截图中的传感器数值为模拟输入，固件显示现有快照服务的实时数据。

验证覆盖圆形遮罩及黑色四角、表盘上下拖动不滚动且不误触快捷入口、两张主页面横向切换、七个独立入口、圆盘天气/心率/校时点击、圆盘外空白点击不导航及左滑入口、各详情页的真实控件、磁校准、亮度滑块隔离、离线状态、返回历史与滚动位置恢复、按键消抖和长按不重复，以及连续200次主页面切换和70次功能页往返的内存回收。预览RTC输入为08:36:50，表盘显示08:36，心率与温度为模拟的72BPM和26.3°C，固件没有写死这些数值。
`python tests/sensors/run.py`另编译真实LCD/触摸驱动，使用`Core/Inc/main.h`的引脚宏，检查调度前后延时、九时钟恢复、硬复位、候选地址探测及连续失败后的恢复。LCD/触摸的毫秒等待在调度器运行时让出CPU；触摸恢复仍会暂停UI约310～510ms，传感器任务可在等待期间运行。该测试模拟HAL/RTOS，不验证实际总线波形或任务调度，也不覆盖LVGL的DMA异步flush链路。
`python tests/clock/run.py`验证真实RTC封装及校时解析器；UI测试还验证蓝牙分段校时、时分显示、RTC秒值及自主走时、午夜换日及未校时/RTC错误显示。所有主机时间和输入均为模拟，实机LSE与RTC走时仍须烧录后确认。
