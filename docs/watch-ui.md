# 手表深色 UI

本界面直接使用项目现有的 LVGL 8.2、ST7789 240×280 显示驱动和 CST816 触摸驱动。启动入口仍为 `App_UI_Create()`，无需调整 Keil 工程的源文件列表。

## 页面与交互

| 页面 | 内容 | 操作 |
| --- | --- | --- |
| WATCH | 大号运行时间、秒进度环、传感器与设置入口 | 左滑进入 SENSORS；上下滑动浏览入口卡片 |
| SENSORS | 姿态与气压入口、在线状态 | 左滑进入 SETTINGS，右滑进入 WATCH；点击卡片进入详情 |
| SETTINGS | 背光亮度、交互说明 | 右滑进入 SENSORS；上下滑动浏览；拖动滑块调整 10%–100% 亮度 |
| MOTION | Pitch、Roll、Yaw 三轴姿态角 | 上下滑动查看数据；右滑或按实体键返回 |
| ENVIRONMENT | 气压 hPa、估算海拔 m | 上下滑动查看说明；右滑或按实体键返回 |

三张主页面在边缘停止切换，不循环跳页。底部三个圆点表示主页面位置；详情页沿用传感器页的圆点。

实体键使用已有 `KEY_1`（PA5，上拉输入，低电平按下）。按下和释放均做 30 ms 消抖，释放后触发一次返回；持续按住不会连续返回。返回按实际访问历史执行，并恢复上一页的纵向滚动位置。无历史时按键保持当前页面。历史保存最近 16 次页面访问。

横向滑动使用 LVGL 手势，累计 40 px 位移触发，触摸芯片重复上报坐标时仍保留累计位移，支持慢速滑动。纵向滚动仅作用于中间内容区域；标题和底部位置指示固定。亮度滑块不向页面传递横向手势。页面切换在手指释放后执行，使用 160 ms 动画并自动删除旧页面，避免在触摸回调中删除事件对象。动画期间忽略新的页面点击和手势；实体键返回会排队等待动画结束。

按用户要求保留原触摸和显示配置：LVGL任务、触摸读取、显示刷新调度均为5ms；调度周期不代表屏幕实际帧率。界面数值仍每100ms更新。触摸连续失败200次后恢复，维持约1s的原恢复节奏。主频100MHz、RTOS tick1000Hz、背光和休眠行为保持原配置。

## 配色与数据

背景 `#080C12`，卡片 `#121B28`，分隔与轨道 `#253348`；深蓝 `#386AC2` 和暗橙 `#CE7438` 用于重点数据。文字使用灰色提高可读性，无浅色背景。复用现有 Montserrat 10/14/20/30 字体，固件界面采用英文，避免引入当前未启用的中文字库。关闭 `LV_USE_PERF_MONITOR`，屏幕不显示 FPS/CPU 调试浮层。

姿态和气压每 100 ms 经 `App_IMU_GetSnapshot()`、`App_Baro_GetSnapshot()` 获取；UI 不直接访问传感器 I2C。无有效快照时显示 `NO DATA` 与 `--`。Yaw 由四元数反解到 (-180, 180]：有效磁场参与时以磁北为参考，失效时继续六轴相对递推。姿态页显示 `MAG NORTH`、`MAG UNCAL` 或 `GYRO ONLY`，并增加三轴磁场和旋转校准按钮。高度保持原有标准海平面气压估算方式。磁力计接线、校准与融合约定见 [magnetometer.md](magnetometer.md)。

项目未启用 RTC，因此表盘 `RUN TIME` 显示开机累计时长，圆环显示秒进度。亮度默认 30%，通过现有 `LCD_Set_Light()` 调节；重启后恢复默认值，尚未持久化到 Flash。

所有 LVGL 调用仍在显示任务中运行。其他任务若调用 `App_UI_Back()`，必须持有 `App_Display_Lock()`；中断中禁止调用。

## 验证与预览

Keil：构建 `MDK-ARM/f411ceu6.uvprojx`，输出仍位于 `MDK-ARM/f411ceu6/`。无需烧录即可编译，实际触摸手感与背光效果需要上板验证。

桌面验证使用项目真实的 LVGL 绘制器和输入引擎，只替换 GPIO、传感器快照和背光接口：

```powershell
python tests/ui/run.py
```

需要桌面 GCC（Windows 可使用 MinGW）、Python 和 Pillow。输出位于忽略跟踪的 `tests/ui/output/`，包含实际界面渲染图及页面预览拼图。截图中的传感器数值为模拟输入，固件显示现有快照服务的实时数据。

验证覆盖横向切换、卡片点击、上下滚动、亮度滑块与切页隔离、离线数据状态、返回历史与滚动位置恢复、按键消抖和长按不重复返回，以及连续 200 次切换后的内存回收。
