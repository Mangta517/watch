# RTC 三针表盘与功能入口

本界面直接使用项目现有的 LVGL 8.2、ST7789 240×280 显示驱动和 CST816 触摸驱动。启动入口为 `App_UI_Create()`，RTC驱动与校时解析模块已加入Keil工程。开机先完成LCD/触摸初始化并刷新首帧，再在LVGL任务内初始化RTC及蓝牙；此期间界面暂时停留在首帧。随后创建原有sensor任务，在后台初始化传感器、恢复校准并采样；未获得数据时显示占位或现有状态。

## 页面与交互

| 页面 | 内容 | 操作 |
| --- | --- | --- |
| WATCH | 240×280全屏深蓝背景、无外层圆形边框和裁切、时针/分针/秒针、数字时分、温湿度/心率/电池摘要 | 左滑打开功能网格；点击温湿度/心率进入详情，点击刻度盘或数字时间进入Bluetooth校时；上下拖动不滚动也不触发入口 |
| APPS | Heart rate、Motion、Barometer、Climate、Weather、Bluetooth、Display七个独立入口控件 | 上下滚动网格，点击进入对应详情；右滑或BACK返回表盘 |
| HEART RATE | BPM、测量状态、原始信号与周期诊断 | START/STOP控制现有心率测量 |
| MOTION | Pitch/Roll/Yaw、磁场三轴、融合来源及校准状态 | 上下滚动查看；CALIBRATE MAG/FINISH CALIBRATION沿用原校准接口 |
| BAROMETER | 气压、标准海平面气压估算海拔及传感器状态 | 上下滚动查看 |
| CLIMATE | AHT21空气温湿度、采样次数及CRC/I2C等状态 | 自动更新 |
| WEATHER | 手机天气、温度、湿度及距同步时间 | 由现有BLE天气协议同步 |
| BLUETOOTH | BLE初始化结果、接收内容、发送及校时结果 | SEND TEST发送测试文本；CLEAR清空接收记录 |
| DISPLAY | 背光亮度 | 拖动滑块调整10%–100%亮度 |

WATCH与APPS两张主页面在横向边缘停止切换，不循环跳页。每个功能通过独立控件进入独立详情页。刻度盘使用恢复的60格刻度与1～12数字，不绘制圆形背景板或边框，白色时针、橙色分针、红色秒针及浅蓝中心轴；背景铺满矩形屏幕，底部显示本地 AHT21 温湿度、心率和电池电压数据。

详情页右滑、点击标题或BACK、按侧键，均通过原访问历史返回，并恢复入口网格的纵向滚动位置。主表盘不显示标题、APPS文字或页码圆点，背景铺满屏幕；APPS与各详情页继续显示原有标题、返回入口及功能区圆点。

实体键使用已有 `KEY_1`（PA5，上拉输入，低电平按下）。按下和释放均做 30 ms 消抖，释放后触发一次返回；持续按住不会连续返回。返回按实际访问历史执行，并恢复上一页的纵向滚动位置。无历史时按键保持当前页面。历史保存最近 16 次页面访问。

电源键 SW2 使用 `WAKE`（PA4，上升沿 EXTI4、无内部上下拉、中断优先级 13）。UI 定时器扫描电平，按下和释放均做 30 ms 消抖，按下消抖通过后切换背光：熄屏设为 0%，亮屏恢复亮度滑块原值；按住不重复切换，开机时按住 SW2 后首次松手不会熄屏。熄屏期间暂停触摸输入和 PA5 返回操作，保留页面、滚动位置和亮度；亮屏时等待已有触点释放。EXTI4 仅由 HAL 清除中断，不在 ISR 中调用 LVGL 或背光接口。

PA3 `POWER_EN` 在 `main()` 入口、HAL和系统时钟初始化前就设置为高电平输出，随后CubeMX GPIO初始化继续保持高电平，保持 TPS63020 供电；`.ioc` 同步设置初始高电平，重新生成代码后仍保留。当前熄屏仅关闭背光，LCD、MCU、传感器和蓝牙继续运行，不进入 Sleep/Stop，也不执行长按关机。

横向滑动使用 LVGL 手势，累计 40 px 位移触发，触摸芯片重复上报坐标时仍保留累计位移，支持慢速滑动。表盘显示三针、数字时间及温湿度/心率快捷控件；功能网格和详情页的纵向滚动仅作用于中间内容区域，标题和底部位置指示固定。亮度滑块不向页面传递横向手势。页面切换在手指释放后执行，使用原有160ms时长的新页滑入动画及缓入缓出曲线，旧页保持静止。两张主页面首次访问时创建，此后左右切换复用；进入详情时释放主页面缓存，详情页往返仍在动画结束后删除旧页。页面加载完成事件结束切页保护，避免在触摸回调中删除事件对象。动画期间忽略新的页面点击和手势；实体键返回会排队等待动画结束。

按用户要求保留原触摸和显示配置：LVGL任务、触摸读取、显示刷新调度均为5ms；调度周期不代表屏幕实际帧率。表盘数据按RTC秒值每秒更新，详情页数据继续每100ms更新；动画期间暂停数据刷新。触摸连续失败200次后恢复，维持约1s的原恢复节奏。主频100MHz、RTOS tick1000Hz保持原配置；PA4仅切换背光，不改变MCU运行模式。

## 配色与数据

表盘与功能页背景 `#041426`，卡片 `#0C2238`，分隔与轨道 `#173B54`；浅蓝 `#70C5E8` 与白色 `#F4FAFF`。传感器重点数据继续使用橙/绿/红色，复用现有Montserrat 10/14/20/30字体。三针使用原生LVGL线条，刻度使用绘图回调；不为秒针创建持续动画。20×20心形使用原有400字节Flash透明度图，表盘、网格入口和心率详情共用。固件界面采用英文；`LV_USE_PERF_MONITOR`保持关闭。原SYDNEY字模文件及许可保留，当前三针表盘不引用该字模。

姿态和气压每 100 ms 经 `App_IMU_GetSnapshot()`、`App_Baro_GetSnapshot()` 获取；UI 不直接访问传感器 I2C。无有效快照时显示 `NO DATA` 与 `--`。Yaw 由四元数反解到 (-180, 180]：有效磁场参与时以磁北为参考，失效时继续六轴相对递推。姿态页显示 `MAG NORTH`、`MAG UNCAL` 或 `GYRO ONLY`，并增加三轴磁场和旋转校准按钮。高度保持原有标准海平面气压估算方式。磁力计接线、校准与融合约定见 [magnetometer.md](magnetometer.md)。

表盘时间来自STM32内部RTC，使用已有32768Hz LSE晶振，预分频127/255，采用24小时制。每100ms轻量读取RTC时间判断秒值变化；同一秒直接返回，不读取表盘摘要、不设置指针。秒值变化后，使用同一快照更新三针、数字时分、电池、心率及本地温湿度摘要，秒针每秒跳6°，时针/分针包含秒偏移；整数坐标不变的指针不重绘。RTC不可用或未校时时，摘要以1秒周期更新，指针隐藏，显示`RTC ERROR`或`SET VIA BLE`；恢复或蓝牙校时时重新显示实际时间。切回表盘立即读取当前快照，不等待下一秒。此改动减少UI快照和绘制开销，没有改变RTC配置、采样任务或MCU运行模式；实际功耗需实板测量。

手机发送`14:35:47`即可校时为14:35:47；继续兼容`14:35`及`9:5`，省略秒时置零。可带CR/LF；不带换行时等待200ms接收空闲再解析。错误、超范围或过长的时间消息不覆盖现有时钟。校时结果在Bluetooth页显示，原始消息仍保留在接收日志。初始化通过RTC备份寄存器标记判断是否已有时间，复位时不重复清零；掉电保持取决于VBAT和LSE是否持续供电。手机发送时分秒，RTC日期为内部占位，不代表手机日期。

亮度默认50%，通过现有`LCD_Set_Light()`调节；重启后恢复默认值，尚未持久化到Flash。

表盘心率摘要使用浅蓝色实心心形加BPM数字；Heart rate网格入口和详情页沿用相同心形图案。点击入口或表盘心率控件打开独立心率页。点击START后，现有sensor任务重新确认EM7028 PID和配置，再开启HRS1采样及PB15外部照明；STOP关闭测量。UI每100ms读取互斥锁保护的快照，不访问I2C。有效波形显示BPM及TRACKING；等待、信号不足和故障分别显示MEASURING、NO SIGNAL、UNAVAILABLE，数值显示`--`。正常测量时显示HRS1原始值、AC变化幅度及最近检测到的PERIOD间隔（ms）；UNAVAILABLE时显示I2C读写、PID/配置读回不符或DATA CHANGED等失败原因及REG地址，具体含义见[em7028.md](em7028.md)。离开心率页不自动停止测量，需要点击STOP。

心率服务每30ms尝试采样，共用去背景、低通滤波后运行10%、20%、30%、40%、50%五档峰谷门限，各候选连续三个相近间隔后，按RR间隔方差最小选优，显示范围为40～200BPM。该选优思路参考HeartPy，来源和适配差异见[em7028.md](em7028.md)。门限最低8计数、完整周期峰谷差至少16计数；范围外或无有效候选显示`--`，不钳成40或200。超过250ms无有效采样、采样间隔超过120ms、弱周期或总线持续故障都会使旧BPM失效。算法尚需实板波形、噪声及参考心率对照校准。

Climate入口打开独立 AHT21 温湿度页，每 2 秒自动采样，显示湿度、空气温度、成功次数及 CRC/I2C/未校准/转换超时状态。UI 只读快照，80ms 转换等待由 sensor 任务分次处理，详见 [aht21.md](aht21.md)。

LVGL池继续保持44KiB；两张主页面左右切换时驻留，进入详情前释放隐藏主页面，各详情页只创建自己的控件。2026-10-14三针版本主机压力测试最低余量16752字节，覆盖200次主页面切换及70次功能页往返，检查主页面对象复用、缓存释放及内存稳定。FreeRTOS任务、栈配置和显示/触摸周期保持原值。本次未运行Keil构建，按用户要求不生成HEX。主机验证不能替代实板RAM峰值、功耗及触摸流畅度验证。

表盘底部显示电池电压，其余页面继续在右上角显示，例如 `BAT 3.85V`。PA1/ADC1_IN1 由现有 sensor 任务每秒单次采样，UI 只读取互斥锁保护的快照；开机在IMU零偏校准前先发布一次读数。1M/1M 分压按2倍还原，ADC参考电压暂按3300mV，实板可在 `app_battery.h` 的 `APP_BATTERY_VREF_MV` 中按实测VDDA校准。首次采样前显示 `BAT --.--V`，启动/转换/停止失败显示红色 `BAT ADC ERR`，下一秒自动重试。显示的是电压，不据此推断充电状态或电量百分比。

详情页保持每100ms读取快照；表盘摘要与指针在RTC秒值变化时更新。只在最终显示文字、颜色或指针整数坐标变化时设置控件，小数继续沿用原有截断规则，原始值变化但显示位数相同不会重复重绘。

表盘右下角使用本地 AHT21 最新有效快照，分两行显示温度和湿度，例如 `25.0C`、`50.0%`；无有效数据时显示 `--C`、`--%`，点击打开 Climate 页。采样保持每 2 秒一次，表盘随原有秒级摘要刷新。手机天气由蓝牙同步，仅在 Weather 页显示天气说明、温度、湿度及距同步时间；表盘不显示天气说明或旧天气提示。获取和协议见 [bluetooth.md](bluetooth.md)。

所有 LVGL 调用仍在显示任务中运行。其他任务若调用 `App_UI_Back()`，必须持有 `App_Display_Lock()`；中断中禁止调用。

## 验证与预览

Keil：构建 `MDK-ARM/f411ceu6.uvprojx`，输出仍位于 `MDK-ARM/f411ceu6/`。无需烧录即可编译，实际触摸手感与背光效果需要上板验证。

桌面验证使用项目真实的 LVGL 绘制器和输入引擎，只替换 GPIO、传感器快照和背光接口：

```powershell
python tests/ui/run.py
```

需要桌面 GCC（Windows 可使用 MinGW）、Python 和 Pillow。输出位于忽略跟踪的 `tests/ui/output/`，包含实际界面渲染图、主页/入口预览`watch-ui-preview.png`及七项功能详情预览`watch-ui-details.png`。截图中的传感器数值为模拟输入，固件显示现有快照服务的实时数据。

验证覆盖全屏矩形布局及无圆形裁切、表盘上下拖动不滚动且不误触快捷入口、两张主页面横向切换、七个独立入口、表盘温湿度/心率/校时点击、底部非入口区域点击不导航及左滑入口、各详情页的真实控件、磁校准、亮度滑块隔离、离线状态、返回历史与滚动位置恢复、按键消抖和长按不重复，以及连续200次主页面切换和70次功能页往返的对象复用及内存稳定、RTC秒内无重绘/摘要读取、下一秒指针及摘要更新。预览RTC输入为08:36:50，三针对应08:36:50，数字时间显示08:36，心率和温湿度为测试桩提供的模拟数据，固件没有写死这些数值。
`python tests/sensors/run.py`另编译真实LCD/触摸驱动，使用`Core/Inc/main.h`的引脚宏，检查调度前后延时、九时钟恢复、硬复位、候选地址探测及连续失败后的恢复。LCD/触摸的毫秒等待在调度器运行时让出CPU；触摸恢复仍会暂停UI约310～510ms，传感器任务可在等待期间运行。该测试模拟HAL/RTOS，不验证实际总线波形或任务调度，也不覆盖LVGL的DMA异步flush链路。
`python tests/clock/run.py`验证真实RTC封装及校时解析器；UI测试还验证蓝牙分段校时、时分显示、RTC秒值及自主走时、午夜换日及未校时/RTC错误显示。所有主机时间和输入均为模拟，实机LSE与RTC走时仍须烧录后确认。
