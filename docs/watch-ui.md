# 手表深色 UI

本界面直接使用项目现有的 LVGL 8.2、ST7789 240×280 显示驱动和 CST816 触摸驱动。启动入口为 `App_UI_Create()`，RTC驱动与校时解析模块已加入Keil工程。

## 页面与交互

| 页面 | 内容 | 操作 |
| --- | --- | --- |
| WATCH | 60刻度、1–12数字、时针/分针/秒针、24小时数字时间 | 手机经BLE发送HH:MM校时；左滑进入SETTINGS；表盘固定，不支持上下滚动 |
| SETTINGS | 背光亮度、蓝牙入口、心率小窗口、Motion姿态/磁场/校准、Environment气压/海拔 | 上下滑动直接浏览全部功能和数据；心率START/STOP控制测量；右滑进入WATCH；点击Bluetooth查看接收数据；拖动滑块调整10%–100%亮度 |
| BLUETOOTH | BLE初始化结果、接收内容、发送及校时结果 | Send Test发送测试文本；Clear清空接收记录；右滑或侧键返回Settings |

两张主页面在边缘停止切换，不循环跳页。底部两个圆点表示主页面位置；蓝牙页沿用设置页的圆点。Motion和Environment直接显示在设置长页面中，不再通过传感器入口跳转到独立详情页。

实体键使用已有 `KEY_1`（PA5，上拉输入，低电平按下）。按下和释放均做 30 ms 消抖，释放后触发一次返回；持续按住不会连续返回。返回按实际访问历史执行，并恢复上一页的纵向滚动位置。无历史时按键保持当前页面。历史保存最近 16 次页面访问。

电源键 SW2 使用 `WAKE`（PA4，上升沿 EXTI4、无内部上下拉、中断优先级 13）。UI 定时器扫描电平，按下和释放均做 30 ms 消抖，松手后切换背光：熄屏设为 0%，亮屏恢复亮度滑块原值；按住不重复切换，开机时按住 SW2 后首次松手不会熄屏。熄屏期间暂停触摸输入和 PA5 返回操作，保留页面、滚动位置和亮度；亮屏时等待已有触点释放。EXTI4 仅由 HAL 清除中断，不在 ISR 中调用 LVGL 或背光接口。

PA3 `POWER_EN` 的初始输出已设为高电平，保持 TPS63020 供电；`.ioc` 同步设置初始高电平，重新生成代码后仍保留。当前熄屏仅关闭背光，LCD、MCU、传感器和蓝牙继续运行，不进入 Sleep/Stop，也不执行长按关机。

横向滑动使用 LVGL 手势，累计 40 px 位移触发，触摸芯片重复上报坐标时仍保留累计位移，支持慢速滑动。表盘只显示时钟，没有下方入口卡片；设置和蓝牙页的纵向滚动仅作用于中间内容区域，标题和底部位置指示固定。亮度滑块不向页面传递横向手势。页面切换在手指释放后执行，使用 160 ms 动画并自动删除旧页面，避免在触摸回调中删除事件对象。动画期间忽略新的页面点击和手势；实体键返回会排队等待动画结束。

按用户要求保留原触摸和显示配置：LVGL任务、触摸读取、显示刷新调度均为5ms；调度周期不代表屏幕实际帧率。界面数值仍每100ms更新。触摸连续失败200次后恢复，维持约1s的原恢复节奏。主频100MHz、RTOS tick1000Hz保持原配置；PA4仅切换背光，不改变MCU运行模式。

## 配色与数据

背景 `#080C12`，卡片 `#121B28`，分隔与轨道 `#253348`；深蓝 `#386AC2` 和暗橙 `#CE7438` 用于重点数据。文字使用灰色提高可读性，无浅色背景。复用现有 Montserrat 10/14/20/30 字体，固件界面采用英文，避免引入当前未启用的中文字库。关闭 `LV_USE_PERF_MONITOR`，屏幕不显示 FPS/CPU 调试浮层。

姿态和气压每 100 ms 经 `App_IMU_GetSnapshot()`、`App_Baro_GetSnapshot()` 获取；UI 不直接访问传感器 I2C。无有效快照时显示 `NO DATA` 与 `--`。Yaw 由四元数反解到 (-180, 180]：有效磁场参与时以磁北为参考，失效时继续六轴相对递推。姿态页显示 `MAG NORTH`、`MAG UNCAL` 或 `GYRO ONLY`，并增加三轴磁场和旋转校准按钮。高度保持原有标准海平面气压估算方式。磁力计接线、校准与融合约定见 [magnetometer.md](magnetometer.md)。

表盘时间来自STM32内部RTC，使用已焊接的32768Hz LSE晶振，预分频127/255，采用24小时制。小时针随分钟、秒推进，分钟针随秒推进；细红色秒针每秒跳动一格（6度），底部显示HH:MM。三根指针均使用RTC时间；未校时或RTC错误时隐藏全部指针。首次未校时时显示`--:--`及`SET VIA BLE`，不把开机时长当作真实时间；RTC不可用时显示`RTC ERROR`。

手机发送`14:35`即可校时为14:35:00，也支持`9:5`归一为09:05。可带CR/LF；不带换行时等待200ms接收空闲再解析。错误、超范围或过长的时间消息不覆盖现有时钟。校时结果在Bluetooth页显示，原始消息仍保留在接收日志。初始化通过RTC备份寄存器标记判断是否已有时间，复位时不重复清零；掉电保持取决于VBAT和LSE是否持续供电。手机只发时分，RTC日期为内部占位，不代表手机日期。

亮度默认50%，通过现有`LCD_Set_Light()`调节；重启后恢复默认值，尚未持久化到Flash。

心率卡片在Bluetooth入口下方，向上滚动即可看到。点击START后，现有sensor任务重新确认EM7028 PID和配置，再开启HRS1采样及PB15外部照明；STOP关闭测量。UI每100ms读取互斥锁保护的快照，不访问I2C。有效波形显示BPM及TRACKING；等待、信号不足和故障分别显示MEASURING、NO SIGNAL、UNAVAILABLE，数值显示`--`。正常测量时显示HRS1原始值、AC变化幅度及最近检测到的PERIOD间隔（ms）；UNAVAILABLE时显示I2C读写、PID/配置读回不符或DATA CHANGED等失败原因及REG地址，具体含义见[em7028.md](em7028.md)。离开设置页不自动停止测量，需要点击STOP。

心率服务每30ms尝试采样，共用去背景、低通滤波后运行10%、20%、30%、40%、50%五档峰谷门限，各候选连续三个相近间隔后，按RR间隔方差最小选优，显示范围为40～200BPM。该选优思路参考HeartPy，来源和适配差异见[em7028.md](em7028.md)。门限最低8计数、完整周期峰谷差至少16计数；范围外或无有效候选显示`--`，不钳成40或200。超过250ms无有效采样、采样间隔超过120ms、弱周期或总线持续故障都会使旧BPM失效。算法尚需实板波形、噪声及参考心率对照校准。

环境区末尾新增 AHT21 温湿度测试卡片，每 2 秒自动采样，显示湿度、空气温度、成功次数及 CRC/I2C/未校准/转换超时状态。UI 只读快照，80ms 转换等待由 sensor 任务分次处理，详见 [aht21.md](aht21.md)。

为保留心率及 AHT21 卡片的动画切页内存余量，LVGL池为44KiB；2026-10-13 主机压力测试最低余量4360字节。FreeRTOS任务、栈配置和显示/触摸周期保持原值。

此前心率版本的Keil构建总Code为186076字节、RO-data为92288字节，RW+ZI为92576字节。AHT21 版本当前构建与资源记录见 [aht21.md](aht21.md)。主机模拟不能替代实板RAM峰值、光路、ADC更新周期与心率准确性验证。

所有 LVGL 调用仍在显示任务中运行。其他任务若调用 `App_UI_Back()`，必须持有 `App_Display_Lock()`；中断中禁止调用。

## 验证与预览

Keil：构建 `MDK-ARM/f411ceu6.uvprojx`，输出仍位于 `MDK-ARM/f411ceu6/`。无需烧录即可编译，实际触摸手感与背光效果需要上板验证。

桌面验证使用项目真实的 LVGL 绘制器和输入引擎，只替换 GPIO、传感器快照和背光接口：

```powershell
python tests/ui/run.py
```

需要桌面 GCC（Windows 可使用 MinGW）、Python 和 Pillow。输出位于忽略跟踪的 `tests/ui/output/`，包含实际界面渲染图及页面预览拼图。截图中的传感器数值为模拟输入，固件显示现有快照服务的实时数据。

验证覆盖表盘上下拖动不滚动、两张主页面横向切换、设置页同时显示Motion和Environment、磁校准按钮、蓝牙卡片点击、上下滚动、亮度滑块与切页隔离、离线数据状态、返回历史与滚动位置恢复、按键消抖和长按不重复返回，以及连续200次切换后的内存回收。预览拼图中的SETTINGS / TOP、MOTION、ENVIRONMENT是同一长页面的不同滚动位置。
`python tests/sensors/run.py`另编译真实LCD/触摸驱动，使用`Core/Inc/main.h`的引脚宏，检查调度前后延时、九时钟恢复、硬复位、候选地址探测及连续失败后的恢复。LCD/触摸的毫秒等待在调度器运行时让出CPU；触摸恢复仍会暂停UI约310～510ms，传感器任务可在等待期间运行。该测试模拟HAL/RTOS，不验证实际总线波形或任务调度，也不覆盖LVGL的DMA异步flush链路。
`python tests/clock/run.py`验证真实RTC封装及校时解析器；UI测试还验证蓝牙分段校时、表盘指针方向、自主走时、午夜换日及未校时/RTC错误显示。所有主机时间和输入均为模拟，实机LSE与RTC走时仍须烧录后确认。
