# RTC 三针表盘与功能入口

2026-10-28当前省电配置：普通APP和升级APP使用64MHz、Scale3、Flash 2等待周期；HSI/8×128/4，APB1=32MHz、APB2=64MHz、SPI1=32MHz。TIM3预分频为64，计数仍为1MHz；软件I2C为51/102次位延时，触摸为51次，Bootloader保留原值。Tickless默认启用STOP，BLE开启时保留Sleep实时接收，BLE关闭且熄屏、外设空闲时进入STOP，醒后恢复64MHz。STOP启用Flash掉电和低功耗稳压器低电压模式；屏幕睡眠后停止TIM3并关闭TIM3/SPI1/DMA2时钟，亮屏先恢复时钟再发Sleep Out，背光仍保持0直至应用恢复亮度。ADC在Sleep期间停钟；空闲PA0/PA2/PA6/PA7/PB10/PC13为模拟无上下拉，移除PA3及LCD控制/心率LED推挽输出的内部下拉。手机诊断仍由DIAG,1/DIAG,0加换行控制，默认静默，心率波形关闭。此前84MHz/Sleep及48MHz记录均为历史配置，任务调度和传感器档位继续沿用；未烧录或实测电流。

2026-10-27低功耗档位：普通APP和升级APP固定48MHz、Scale 3、Flash 1等待周期；HSI/8×96/4，APB1=24MHz、APB2=48MHz、SPI1=24MHz。TIM3预分频为48，保留1MHz计数和约3.32kHz背光PWM；软件I2C的67/134次延时按48/84缩放并留约5%余量为40/80次，触摸位延时同为40次；Bootloader仍为100MHz，保留原67/134次延时，避免降频过度拉长100Hz采样占用。GPIO调用等开销会随降频增加，实际总线时序和采样裕量需上板确认。活跃时LVGL/touch按5ms服务；自动熄屏及PA4熄屏后，无按键时LVGL等待PA4通知或100ms期限，按住/消抖期间约20ms服务，touch任务发送芯片休眠命令后阻塞，PA4通知后恢复。未开启独立运动模式时，姿态页、MPU/磁校准和保存期间sensor每20ms服务，MPU=50Hz、磁力计=30Hz（每40ms轮询）；后台sensor每40ms服务其他器件，MPU保持5Hz加速度低功耗循环，每200ms读取新帧；磁力计保持休眠，进入姿态页恢复连续六轴和磁场采样。独立运动模式恢复100Hz业务档，见下文。MPU同步调整低通滤波；融合使用实际采样时间，磁帧新鲜度窗口随普通档位为120/400ms。零偏校准保留100帧静止确认和100帧平均，50Hz下合计约4s，阶段超时同步放宽为6/4s；磁校准保留原覆盖范围和样本数要求。心率测量期间sensor改为10ms服务，PPG约30ms读取一次，MPU为100Hz、磁力计75Hz以保留原运动参考；磁校准期间仍为50Hz/30Hz。测量结束恢复原普通档位。亮屏时气压、电池约1s及温湿度约2s；自动熄屏及PA4熄屏后的后台姿态/定时测量周期见下文。

CPU Sleep / STOP / Tickless：所有应用任务阻塞后，由FreeRTOS提供下一任务截止时间，运行时保持1ms SysTick。BLE供电或USART1仍开启、亮屏背光PWM、SPI/DMA/ADC有在途操作时保留Sleep；BLE断电、USART1时钟关闭、屏幕熄灭且上述外设空闲，预计至少5ms空闲时进入低功耗调压器STOP。F411 STOP会停止USART/APB时钟，因此普通BLE待机始终使用Sleep，保证既有串口接收；目前SPORT熄屏后可在100Hz采样间隙使用STOP。两条路径均限制100ms，保留任务周期及原双任务看门狗条件，不在IDLE喂狗。Bootloader不运行FreeRTOS，保持原时基。

STOP进入前暂停SysTick，以LSE/16的RTC WUT提前唤醒，预留约1ms恢复余量；PA4及既有传感器EXTI也能提前唤醒。醒后在中断仍屏蔽时有界恢复PLL，清RSF并等待RTC影子同步，使用亚秒模差值补齐HAL/FreeRTOS，并补上TIM2诊断计数停钟时间；最后恢复原tick相位、1ms节拍并开放中断。最后的到期tick交正常ISR处理，不用vTaskStepTick跨过解阻塞点。时钟恢复及RTC等待均不依赖暂停的HAL tick。RTC未就绪退回1ms Sleep，WUT配置失败退回Tickless Sleep；STOP后影子同步失败会标记RTC未就绪并退回1ms Sleep，本次无法从无效RTC准确还原停钟间隔。若STOP期间LSE停振且没有EXTI，仍由外置看门狗复位，不能依靠已停止的SysTick唤醒。

RTC使用LSE，异步/同步分频改为0/32767，日历仍为1Hz，亚秒分辨率约30.5us；同步计数频率升高的RTC自身功耗代价也须计入整板测量。首次升级时迁移已初始化备份域的分频，保留日历及备份标记，迁移会重新开始亚秒相位。休眠只取小于1秒的亚秒模差值，不取日历差值；手机校时在应用任务恢复后执行，因此不会改变超时、采样或开机累计时间。DWT周期计数补偿RTC测量区间之外的停表计算开销，不依赖DWT在Sleep/STOP中计数；RTC量化和最后几条寄存器操作仍有有限误差，长期精度须实测。普通熄屏的每秒IMU快照保留融合四元数，唤醒只重置采样时间与新鲜度，避免航向每秒从0重新收敛；休眠期间未采集的转动不会被积分。当前熄屏显示循环无按键时等待PA4/UART通知或100ms期限，消抖/按住期间约20ms推进，触摸任务在芯片休眠后阻塞，实际连续睡眠受最近任务截止时间限制；100ms只是上限，不代表每次能睡满100ms。

2026-10-23自动熄屏：亮屏时连续10秒无触摸，与PA4手动熄屏共用同一处理函数：背光为0%，暂停显示刷新及LVGL绘图/动画，禁用触摸并清空缓存，普通模式保持蓝牙供电及USART1；LCD等待在途DMA正常完成或100ms超时安全收尾后发Sleep In，触摸由其独占任务发送休眠命令，随后通过任务通知无限等待PA4唤醒。自动熄屏后触摸不能唤醒，由PA4或辅助抬腕恢复；恢复原亮度、当前RTC时间和原页面位置，LCD发Sleep Out并等待至少120ms后恢复显示，触摸任务通过通知唤醒、复位及探测芯片（复位等待约310ms），等待原触点松开后才接收新手势。持续触摸及亮屏按键操作仍算活动。运动、心率及校准所需采样按各自原策略处理，CPU使用上述Sleep/STOP混合策略。

2026-10-22熄屏优化：熄屏后暂停显示刷新定时器，并跳过`lv_timer_handler()`，不再推进绘图/动画；按键消抖、在途DMA收尾、已中止的心率发送结果和看门狗仍由显示循环推进；普通模式的蓝牙供电及USART1不随熄屏关闭。亮屏恢复定时器并请求完整重绘，下一次LVGL处理按当前tick完成已到期的动画、刷新数据；不重建页面，保留位置及原触点松手隔离。熄屏传感器改为下面的定时采样策略，CPU空闲策略已由2026-10-27的Sleep/STOP混合方案更新。

本界面直接使用项目现有的 LVGL 8.2、ST7789 240×280 显示驱动和 CST816 触摸驱动。启动入口为 `App_UI_Create()`。开机先初始化LCD、注册缓存输入并刷新首帧，随后创建sensor和touch任务；RTC及蓝牙启动在LVGL循环中分步推进。sensor后台初始化传感器、恢复校准并采样，touch独占触摸初始化、读取及恢复；尚无数据时显示占位或无触摸。

## 页面与交互

独立运动模式从APPS的“Sport mode”进入专用页面，点击START SPORT开始、STOP SPORT结束，姿态页保留测量和校准显示。模式跨页面保留，重启默认关闭。开启后先完成正在进行的启动校准与EEPROM保存，再切换sensor为10ms、MPU及欧拉角100Hz、磁力计75Hz（10ms轮询、50ms新鲜度），心率自动连续测量并按30ms读取；PA4熄屏仍保持此测量频率，不使用普通熄屏的10分钟/10秒窗口。运动期间心率硬件故障停测，重新切换模式后才重试，心率页按钮显示SPORT。退出恢复原手动心率请求及普通亮屏/熄屏策略。

运动模式下蓝牙供电和USART1关闭，亮屏也不打开；气压置standby并暂停读取及恢复重试，气压页显示PAUSED。停止新校准与校准保存，沿用RAM中的校准参数；EEPROM仅每10分钟短暂记录开机时间，访问间隙引脚保持模拟模式。退出运动模式后气压等待新转换恢复，柱状图保留缺测空位，不用新数据补画暂停时段；蓝牙仅在亮屏时重新启动。电池、触摸及看门狗继续原服务，温湿度保持普通亮屏周期。

WATCH与APPS两张主页面在横向边缘停止切换，不循环跳页。每个功能通过独立控件进入独立详情页。刻度盘使用恢复的60格刻度与1～12数字，不绘制圆形背景板或边框，白色时针、橙色分针、红色秒针及浅蓝中心轴；背景铺满矩形屏幕，底部显示本地 AHT21 温湿度、心率和电池电压数据。

详情页右滑固定返回APPS功能网格：从网格进入时恢复原纵向滚动位置，从表盘快捷入口进入时显示网格顶部；再次右滑返回表盘。Bluetooth统一从功能网格进入。点击标题或BACK、按侧键仍通过原访问历史返回。主表盘不显示标题、APPS文字或页码圆点，背景铺满屏幕；APPS与各详情页继续显示原有标题、返回入口及功能区圆点。

实体键使用已有 `KEY_1`（PA5，上拉输入，低电平按下）。按下和释放均做 30 ms 消抖，释放后触发一次返回；持续按住不会连续返回。返回按实际访问历史执行，并恢复上一页的纵向滚动位置。无历史时按键保持当前页面。历史保存最近 16 次页面访问。

电源键 SW2 使用 `WAKE`（PA4，上升沿 EXTI4、无内部上下拉、中断优先级 13）。UI 定时器扫描电平，按下和释放均做 30 ms 消抖，按下消抖通过后切换背光：熄屏设为 0%，亮屏恢复亮度滑块原值；按住不重复切换，开机时按住 SW2 后首次松手不会熄屏。熄屏期间暂停触摸输入和 PA5 返回操作，保留页面、滚动位置和亮度；亮屏时等待已有触点释放。EXTI4 仅由 HAL 清除中断，不在 ISR 中调用 LVGL 或背光接口。

PA3 `POWER_EN` 在 `main()` 入口、HAL和系统时钟初始化前就设置为高电平输出，随后CubeMX GPIO初始化继续保持高电平，保持 TPS63020 供电；`.ioc` 同步设置初始高电平，重新生成代码后仍保留。当前熄屏关闭背光和显示处理，传感器采用定时测量/休眠，LCD仍保持供电，蓝牙普通模式在PA4熄屏后保持供电/UART、SPORT模式关闭，CPU空闲时按上述条件进入Sleep或STOP，不执行Standby或长按关机。

横向滑动使用 LVGL 手势，累计位移超过40 px触发，触摸芯片重复上报坐标时仍保留累计位移，支持慢速滑动。功能网格和表盘温湿度/心率入口在按住期间，任一坐标偏离按下点超过10 px就取消本次点击；即使未达到翻页门槛、或手指又移回起点，也不会误入详情。表盘显示三针、数字时间及温湿度/心率快捷控件；功能网格和详情页的纵向滚动仅作用于中间内容区域，标题和底部位置指示固定。亮度滑块不向页面传递横向手势。页面切换在手指释放后执行，使用原有160ms时长的新页滑入动画及缓入缓出曲线，旧页保持静止。两张主页面首次访问时创建，此后左右切换复用；进入详情时释放主页面缓存，详情页往返仍在动画结束后删除旧页。页面加载完成事件结束切页保护，避免在触摸回调中删除事件对象。动画期间忽略新的页面点击和手势；实体键返回会排队等待动画结束。

2026-10-21触摸独立任务：LVGL优先级3、sensor优先级2、touch优先级1。touch栈256字（1KB），目标周期5ms，超期后重新计时，不补跑旧轮询；LVGL任务和显示/输入消费仍为5ms，调度周期不代表屏幕实际帧率。表盘数据按RTC秒值每秒更新，气压详情每5s更新，其他详情页数据继续每100ms更新；动画期间暂停数据刷新。触摸连续失败200次后逐步恢复，实际间隔会随低优先级任务被抢占而延长。主频100MHz、RTOS tick1000Hz保持原配置；PA4仅切换背光，不改变MCU运行模式。

`app_touch.c`用32项静态事件缓冲保留按下、移动及释放顺序；LVGL回调只在短临界区取数，通过`continue_reading`消费积压，不做I2C或等待。最近采集或队首事件超过100ms、缓冲满时取消旧手势并等待物理松手，避免长按卡住或回放旧点击。熄屏停止新轮询、清空缓存，由touch任务发送芯片休眠命令后阻塞；亮屏通过任务通知恢复触摸复位及探测，清缓存并等待原触点释放；跨熄屏切换的在途I2C结果被丢弃。所有LVGL API仍仅由显示任务调用，看门狗保持原显示/sensor双任务进度条件。

验证：`python tests/touch/run.py`检查短点击/移动/释放顺序、过期、缓冲满、熄屏及在途读取切换、tick回绕；UI回归接入真实缓存桥和LVGL输入移植层，检查短点击、过期不误点击及原滑动/熄屏行为。任务优先级的实际调度效果、触摸手感及栈余量仍需实板验证。
