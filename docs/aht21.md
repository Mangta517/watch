# AHT21 温湿度测试

依据 `F:/1/AHT21.pdf` 奥松 AHT21 产品手册 V1.2，第 6～9 页。

## 接线与共用总线

VDD 接 3.3V，GND 共地，SCL 接 PB14，SDA 接 PB13。芯片 1、6 脚 NC 悬空。
VDD/GND 间按手册放置 10μF 去耦；VDD 必须先于或同步于信号线上电。
SCL/SDA 使用外部上拉到 3.3V，参考 2～4.7kΩ，已有模块上拉需按并联后的等效阻值考虑。
传感器总线现改为开漏输出；内部上拉不能代替外部上拉。TP 总线及软件位延时保持原实现。
`my_i2c_init()` 覆盖 CubeMX 的 SENSOR GPIO 初始输出模式，不需要更换引脚或硬件 I2C 外设。

7 位地址为 0x38，线上写/读地址为 0x70/0x71，与本板 MPU6050、SPL006、磁力计、EM7028 不冲突。
0x71 是读地址，不是需要先写入的状态寄存器号。

## 分层与读取

- `interface/aht21.c`：上电等待 40ms，直接读状态；未校准时发送 BE 08 00，等 10ms 后复查。
- `application/app_aht21.c`：在sensor任务启动阶段初始化；亮屏每1秒、熄屏每60秒发送AC 33 00，STOP后释放总线，页面切换不改变周期。
- 每轮 sensor 服务检查时间，至少 80ms 后读取；busy 时延后到下一轮，200ms 仍忙则显示超时。超过 200ms 尚未处理的转换直接丢弃，不读取或更新采样时间。
- 每帧读 7 字节：状态、5 字节温湿度原始值、CRC。前 6 字节回 ACK，最后 CRC 回 NACK，再 STOP。
- CRC8 初值 FF，多项式 31，校验前 6 字节。忙、CRC 错误或校准位为 0 时不更新数据。
- 采样等待不调用 HAL_Delay/vTaskDelay，不占用 I2C；其他传感器继续按原任务流程采样。
- 快照使用FreeRTOS mutex保护，UI不访问硬件。失败后隐藏旧数值，下一次按当前屏幕状态采样成功后恢复。

湿度原始值：`(b1 << 12) | (b2 << 4) | (b3 >> 4)`。
温度原始值：`((b3 & 0x0F) << 16) | (b4 << 8) | b5`。
先转为 uint32_t 再移位，两者均为 20 位无符号数。
`RH = raw_h * 100 / 1048576`，单位 %RH；`T = raw_t * 200 / 1048576 - 50`，单位 ℃。

## 测试 UI

从表盘左滑进入设置页，向上滚动经过 MOTION、ENVIRONMENT 和气压卡片，即可看到 AHT21 卡片。
显示湿度、空气温度、成功采样次数；所有亮屏页面每1秒采样，熄屏每60秒短采样，SPORT也遵守同一屏幕策略，无需点击启动。进入或离开详情页均不加采，不重置周期；亮屏详情页的次数标签显示`SAMPLES <次数> / 1s`。
ONLINE / CRC OK 表示最近一帧有效；MEASURING 表示正在等待转换，已有有效数值暂时保留。
WAITING 为首帧尚未完成。I2C ERROR、CRC ERROR、NOT CALIBRATED、CONVERSION TIMEOUT 为对应失败原因，数值显示 --。
显示保留一位小数，沿用现有 UI 的定点文本格式。进入/离开页面不停止后台采样。
启动初始化失败或测量帧报告校准位缺失后，服务通过`aht21_recover_begin/step`分步恢复；每步至多一笔事务，保留40ms/10ms最小等待。恢复总超时为1s，覆盖后台40ms及熄屏窗口100ms的调度周期，恢复和一次测量使用约1.6s窗口推进；普通测量仍等待至少80ms，200ms仍忙则超时。恢复期间快照无效，失败后按当前采样周期冷却再尝试（亮屏1s、熄屏60s）。普通CRC错误不触发重初始化。

采样周期使用独立固定时间基准，转换等待从触发事务结束后计时。I2C耗时、恢复过程和读取错误均不后移后续周期；超期只处理当前一次测量，不补跑旧周期。普通低功耗待机每60秒开放约1.6s的温湿度窗口，恢复成功后下一拍触发当前测量；SPORT熄屏同为60s采样，亮屏均恢复1s周期。气压使用独立的5分钟窗口，切页或切换屏幕均不额外触发气压读取。

## 主机验证与实板边界

`python tests/sensors/run.py` 编译真实驱动/服务，替换 I2C、HAL tick 和 RTOS 锁，检查直接读协议、ACK/NACK、STOP、CRC、位拼接、负温度、采样间隔、超时及 tick 回绕。
同一测试还检查共用 SENSOR GPIO 使用开漏，并回归其他传感器和 LCD/触摸驱动。
`python tests/ui/run.py` 使用真实 LVGL 渲染器，模拟 AHT21 快照，检查正常/测量/故障状态、导航和滚动恢复，生成 `tests/ui/output/aht21.png` 等预览。
主机测试与 Keil 编译不能替代实板上拉电阻、SCL 频率/上升沿、地址应答、CRC 读回及温湿度对照验证。
